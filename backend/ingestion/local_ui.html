Your documents. Their original evidence.

Upload a document, run a query, and inspect passages with source citations.

Local development · synthetic retrieval

1. Add a document

TXT, PDF, DOCX body paragraphs or controlled XLSX. Maximum 2 MiB.

PDF has no OCR. DOCX tables and merged spreadsheet cells are unsupported. Spreadsheet citations name the sheet and row.

Use sample or nonconfidential documents. This is a local prototype, not a hosted service.

2. Retrieve evidence

Queries run through the compiled graph and search the stored PostgreSQL corpus.

Synthetic vectors test the application path, not meaning-based relevance. Results are retrieved evidence, not an AI-generated answer. No live Gemini call is made.
Your retrieved passages and citations will appear here.
Original file fingerprints and typed source locations are preserved. A source-code link is not a running assistant link.
